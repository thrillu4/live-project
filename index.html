Introduction

Welcome to Live Projects, a collection of interactive mini-projects designed to help you learn, practice, and experiment with web development. Whether you're looking to build your own To-Do List, work with APIs, or create a functional E-commerce Cart, this platform provides hands-on experience with real-world coding challenges.

Each project is designed to be simple yet practical, allowing you to explore different aspects of frontend and backend development. Feel free to modify, improve, and expand upon them to match your own creative ideas!

Ready to start? Choose a project from the list and dive in! 🚀

Todo List

A simple yet powerful To-Do List application designed to help users organize tasks efficiently. Built with a clean and intuitive interface, this project allows users to add, delete, and manage tasks seamlessly. Tasks are persistently stored using localStorage, ensuring that data remains available even after the browser is closed or refreshed.

The application leverages modern JavaScript, HTML, and CSS to deliver a smooth user experience with a focus on functionality and usability.

Key Features:
  1. Add new tasks with a single click.
  2. Delete tasks individually.
  3. Persistent task storage using localStorage.
  4. Minimalist and responsive design for a distraction-free experience.
This project demonstrates core web development concepts, including DOM manipulation, event handling, and client-side data persistence.

Weather Api

A dynamic weather application that provides real-time weather information for any city worldwide. Powered by a third-party Weather API, this project allows users to search for a location and instantly view current weather conditions, including temperature, humidity, and more.


Built with JavaScript, HTML, and CSS, the application features a clean and responsive design, ensuring a seamless experience across devices.

Key Features:
  1. Real-time weather data fetched via a Weather API.
  2. User-friendly search functionality to check weather by city.
  3. Displays essential weather details like temperature, humidity, and conditions.
This project showcases skills in API integration, asynchronous JavaScript (async/await), DOM manipulation, and delivering a practical and engaging user experience.

E Commerce Cart

A lightweight e-commerce shopping cart application designed to simulate a simple online shopping experience. Users can browse a list of products, add items to their cart, remove items, and proceed to checkout. The cart's contents are persistently stored using localStorage, ensuring that items remain in the cart even after the page is refreshed.


Built with vanilla JavaScript, HTML, and CSS, this project delivers a clean and functional interface with a focus on core web development principles.

Key Features:
  1. Add products to the cart with a single click.
  2. Remove individual items from the cart.
  3. Persistent cart storage using localStorage for seamless user experience.
  4. Real-time cart total calculation and checkout functionality.
  5. Minimalist design with dynamic DOM updates.
This project demonstrates proficiency in DOM manipulation, event handling, client-side data persistence, and JavaScript logic, providing a practical foundation for building e-commerce features.

Expense Tracker

A straightforward and user-friendly Expense Tracker application designed to help users monitor their spending. Users can add expenses with a name and amount, delete entries, and view a running total of all expenses. The application utilizes localStorage to persist expense data, ensuring that records remain available even after the page is refreshed.


Built with vanilla JavaScript, HTML, and CSS, this project offers a clean interface and seamless functionality for personal finance tracking.

Key Features:
  1. Add expenses with a name and amount through an intuitive form.
  2. Delete individual expense entries with a single click.
  3. Persistent data storage using localStorage for reliable record-keeping.
  4. Real-time calculation and display of total expenses.
  5. Simple and responsive design for ease of use across devices.
This project showcases skills in DOM manipulation, event handling, client-side data persistence, and dynamic UI updates, providing a practical tool for managing personal expenses.

Calculator

A versatile and interactive Calculator capable of handling not only basic arithmetic but also advanced operations like square roots, powers, and percentages. Designed with usability in mind, it offers a smooth user experience for a wide range of calculations.


This project was built using vanilla JavaScript, HTML, and CSS, with support for both mouse and keyboard input. Its modern layout and intuitive functionality make it a reliable tool for day-to-day math needs.

Key Features:
  1. Supports both basic and advanced operations: addition, subtraction, multiplication, division, square, square root, inverse (1/x), sign toggle (+/-), and percentages.
  2. Intuitive interface with clear input display and a secondary line showing full expressions.
  3. Keyboard support for convenient data entry and faster interaction.
  4. Error handling for invalid inputs (e.g., division by zero or incorrect symbols).
  5. Responsive, clean, and mobile-friendly design with accessible functionality.
This project showcases essential JavaScript skills, including DOM manipulation, dynamic event handling, and logic structuring—making it a strong example of interactive frontend development.

Quiz App

A compact and engaging Quiz App designed to test users' knowledge through a series of multiple-choice questions. Users can start the quiz, select answers, and view their final score upon completion, with the option to restart for another attempt.


Built with vanilla JavaScript, HTML, and CSS, this project offers a clean and interactive interface, making learning fun and accessible across devices.

Key Features:
  1. Multiple-choice questions with dynamic rendering of questions and answers.
  2. Tracks user score based on correct answers.
  3. Interactive interface with clickable answer options and visual feedback.
  4. Option to restart the quiz to try again.
  5. Responsive design for a seamless experience on desktops and mobile devices.
This project demonstrates skills in DOM manipulation, event handling, state management, and dynamic UI updates, delivering an engaging and educational user experience.
